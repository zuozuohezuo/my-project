## 功能范围

- 虚构清河县初始人口 1,000，三档财富人口、年龄／流民底账与劳力一致汇总。
- 土地建筑产权决定产出去向，民间／官府／皇家池统一保存且余额不重复。
- 有限劳力和原料、生产周期、粮食及加工产出、按群体计算并直接扣池的消费。
- 财富层级不同的短缺影响、死亡和向下转层；整旬候选提交、人口守恒。
- 县档案八个栏目、历史旬报、演示余额调整、明确完整休息旬快捷推进。
- v3 演示县保存恢复、旧局无经济字段时保持原行为、坏数据和日期错配拒绝读取。

## 当前边界

历史开局仍不自动启用全国经济。完整税制、市场、运输、官员 AI、国库内帑年度划拨、出生迁移和建设升级尚未接入；三类归属池只代表当前演示资产归属及余额。县页展示演示真值，正式情报过滤另行实现。

Windows 包使用独立名称 `MingImperialDesk-County`，保留既有 M03 可执行目录。2026-09-08 打包完成并验证：
