## 如何开始

双击项目根目录的 `体验县经济.cmd`，直接进入正常供给情境。也可启动新打包版 `dist/MingImperialDesk-CountyV2/MingImperialDesk-CountyV2.exe`，在主菜单选择“县级经济试玩”，选择正常供给、持续缺粮或生产投入不足。

源码运行：`uv run dynasty --county-demo normal`。另两个情境的参数为 `shortage` 和 `input_shortage`。新建试玩会建立独立数据，不改写历史资料或已有玩家存档。

## 县的初始情况

演示人口 1,000 人，按农民、劳工、手工业者、商人、地主、贵族、官员七类职业统计；同一职业可有不同财富档。财富按人均每旬收入相对基本生活成本评为贫困、普通、富裕。取消年龄组，默认 50% 劳动力比例，新局基础与可用劳力均为 500。自然出生率默认每年 3%、自然死亡率每年 2%，按一年 36 旬累计小数。县内有按民间、官府、皇家归属区分的土地与建筑、生产项目，以及三类资源池。

初始职业人数为：农民 450、劳工 200、手工业者 140、商人 90、地主 60、贵族 20、官员 40；按收入另计贫困 450、普通 450、富裕 100。这两组统计来自同一批人口。

资源包括钱、粮食、原料、日用品和享受品。正常情境民间初始钱 4,000、粮食 30,000；这些是演示单位，不能当作历史银钱田亩或真实人口资料。

县档案保留八个栏目：人口、土地、当地特产、当地修正、钱粮与物资、基础设施、生产经营、民情与秩序。人口、产业与钱粮会实际变化；建设升级、正式市场、税制、全国财政、官员 AI、迁移和完整治安模型仍待后续开发。

## 建议这样测试

1. **正常供给**：点击“休息并推进一旬”，查看生产进度、收获时点、实际消费与余额。正常情境可以跨年继续运行。
2. **持续缺粮**：从主菜单新建该情境，推进 3–4 旬。在“人口”和“民情与秩序”查看不同财富层的健康、劳力、死亡与降层，历史下拉框可以回看各旬。
3. **生产投入不足**：查看“生产经营”中原料不足造成的停工，以及原料到位后的恢复。
4. **自行调整**：在“钱粮与物资”选择归属和资源，填写调整后的余额。可将民间粮食调低观察短缺，或增加粮食查看后续恢复。调整只影响当前演示局，旬初才开放。
5. **人口参数**：在“人口”页调整劳动力比例、年出生率、年自然死亡率和基本生活成本；也可选择群体调整人均收入，查看财富变化。职业不会因为变穷或变富自动更换。
6. **保存读取**：使用右上角保存，退出或切回主菜单后读取。县状态、参数、生产进度和旬报一起恢复，不重复消费。你也可以中途按原 M03 流程行动、处理急报，再存读。

“休息并推进一旬”会明确将当前旬安排为完整休息，通过原 M03 活动和旬末结算推进一次。已有具体活动、未保存的规划草稿、当旬急报、预约或三旬计划时会提示回到起居与朝政处理。该按钮不会跳过必须处理的事件。

## 这一版怎样结算

产业先按可得劳力与原料推进；到收获或加工完成时按建筑、田地归属入池。消费根据三档人数计算，再从共用民间池直接扣除。没有库存预留或逐户钱包。

资源不足时按财富层级计算后果，贫困群体影响最大。基本生活短缺影响健康、劳力和死亡；日用、享受需求不足主要影响满意度。富裕人口可降为普通，普通可降为贫困；财富下降只改变财富档及对应收入，职业不变；自然死亡与缺粮额外死亡分别减少人口，出生增加人口。同一旬转层者不会再按新层级重复受罚。

详细人口规则见[人口职业与收入](../01_系统设计/M05_M06_财政与地方经济/M06_人口职业与收入.md)。收入暂为群体生活水平参数，不向资源池发钱；职业对应的工资、经营收入、地租、官俸及实际转账以后接入。旧县存档继续旧规则，需从主菜单新建县级试玩体验新版职业人口。

钱不会因产出一批实物而自动增加。官府与皇家池不会自动填补民间缺口，正式赈济和财政划拨尚未接入。当前页面展示演示真值，正式皇帝奏报的信息过滤以后实现。

## 示例存档与参数

`artifacts/county_demo/` 已准备正常、缺粮、缺料三份初始存档，以及缺粮推进四旬、正常运行一年后的存档。可以通过游戏内“读取”选择：

- `qinghe_normal.json`
- `qinghe_shortage.json`
- `qinghe_input_shortage.json`
- `qinghe_shortage_after_4_turns.json`
- `qinghe_normal_after_1_year.json`

开发参数集中在 `data/config/county_demo.json`。新建演示县时复制参数，现有存档继续使用自己保存的参数。修改配置适用于下一次新建，页面余额调整则即时作用于当前局。

独立运行检查：`uv run python tools/run_county_demo.py --scenario shortage --turns 4`。

重建截图和示例存档：`uv run python tools/capture_county_demo.py`，输出仅在 `artifacts/county_demo/`，不写玩家存档目录。
