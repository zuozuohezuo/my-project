## 性格与追求更新

2026-09-07：新增第三页签“性格与追求”。稳定性格共九组，去掉“淡泊—好名”，加入谦逊—自负、重情—秉公、守信—权宜、合群—独处；不单列心理状态，心理影响归入既有压力、身体或修正。近期欲望与长期野心支持玩家自设活动条件，实际完成对应活动后才推进，达标保留满足／达成及完成旬记录。

当前 **274 项测试通过**，Ruff 通过。新增验证覆盖九组倾向、旧档补充与坏档拒绝、目标设置与重复阻止、活动完成计数、被替代活动不计、急报／劝谏暂停不计、跨存档与一次达标，以及目标安排按钮不刷进度、不覆盖已满草稿。旧的两页签数量断言已随第三页签更新。

已检查默认页、欲望、野心、达成记录、最小窗口和两个编辑器截图；常规窗口九组性格均可见。`tools/capture_emperor_motives.py` 输出七幅截图和独立演示存档，不改玩家存档。CLI 支持 `--page 5 --emperor-tab 2`，独立程序验收使用此入口检查新页签；构建后的哈希、内容匹配和启动结果见源码 `artifacts/packaged-verification.json`。

当前人格效果、自动欲望生成及具体满足奖励未启用。目标只依据已有活动流程记录完成，不将六次朝政等演示目标等同于实际国家治理成果，也不自动奖励经验、压力恢复或金钱。

## 皇帝健康与修正栏更新

2026-09-07：基础属性页新增健康栏，显示整体健康度与压力（0–100）；疾病、残疾和伤势仅显示异常部位，无异常时隐藏身体明细。新增长期／短期修正列表及两个手动管理对话框。属性当前值与底值分开，技能效果比例与熟练度分开；短期修正仅在成功完成一旬后递减并到期移除。

当前 **246 项测试通过**，Ruff 通过。覆盖修正叠加与下限、超出 100、底值与熟练度保持、旬结算与三旬计划倒计时、急报和劝谏暂停不扣期限、旧存档回填、坏数据拒绝、健康/AP 冲突原子拒绝、身体明细显示隐藏、管理表格增删与目标切换，以及改变 AP 时保留未提交的朝政草稿。

已检查默认健康页、异常及修正样例、技能效果样例、健康编辑器和修正编辑器的实际离屏截图；默认及样例另检查 1180×800 布局，超出高度的内容通过页签滚动访问。新增七幅截图由 `tools/capture_emperor_status.py` 生成，并输出独立的 `皇帝健康修正_演示存档.json`；样例已标注为页面测试数据，不写入玩家存档。独立程序构建后的哈希、随包内容与 Windows 启动结果仍以源码 `artifacts/packaged-verification.json` 为准。

自然疾病、压力变化、恢复、学习成长和技能事件结果尚未模拟；疾病记录不自动推导属性惩罚。属性按点数、技能效果按百分比点叠加及短期按旬计数，是本次实现约定。

## 皇帝属性与技能页面更新

2026-09-07：游戏内新增“06 皇帝档案”，按智力、身体、意志展示 13 项基础属性；技能页签提供六项技能卡片与详情。手动调整支持超过 100 的非负整数，全部字段校验通过后一次应用，取消及非法输入不会造成部分修改。身份、健康、行动安排、时间、诏书和世界数据保持独立；旧 v1 存档可补充缺失的皇帝档案。基础属性 50、技能 0 仅为演示初值，成长和事件判定未启用。

当前 **138 项测试通过**，Ruff 通过。新增验证覆盖数值原子修改、超出常规范围（含大整数）的存读、坏存档拒绝、跨新局独立性、全部控件、技能详情切换、取消、错误后修正、自定义身份、载入新 session 后再编辑，以及朝政草稿保留。已检查属性、技能与编辑器实际离屏截图；1180×800 最小窗口通过页签内部滚动访问全部内容。

`tools/capture_previews.py` 输出十一幅预览，新增文件为 `emperor-attributes-preview.png`、`emperor-skills-preview.png`、`emperor-editor-preview.png`、`emperor-attributes-minimum.png`、`emperor-skills-minimum.png`。独立程序验收脚本已加入皇帝档案截图，并让 Windows 原生隐藏检查实际构建游戏内页面；构建后执行记录、哈希及随包文档核验见源码 `artifacts/packaged-verification.json`。

年度宫廷供给同步记录为定额、每年朝议，暂定一年一拨；本次没有启用财政结算。

## 验证结果

- `uv sync --locked --all-groups` 成功，开发和研究依赖均可用。
- `uv run pytest -q`：47 项通过，包括 35 项核心测试和 12 项 Qt 控件集成测试。
- `uv run ruff check src tests tools`：通过。
- Qt 集成测试操作真实控件及三旬计划对话框，覆盖活动草稿、地图目标、劝谏、急报、存读档和中断恢复。使用离屏平台，测试数据为小型隔离样本。
- 使用完整实际史料另行生成地图、朝政、急报、三旬编辑器、史料及待议页面预览，检查字体、布局和中文显示。
- `uv run python tools/verify_history.py`：完整性通过，历史准确性标为 `limited`。44 条历史来源、2 条字体来源、83 个本地原件／提取文本文件、99 处人物法令证据；引用、父级和地图坐标来源检查无失败项。
- `uv run python tools/build_windows.py`：生成携带解释器、Qt、字体、史料与文档的 Windows 目录式程序。
- `uv run python tools/verify_packaged.py`：检查随包内容哈希；清除 Python 路径覆盖，从独立工作目录启动 EXE，地图／朝政／待议页面离屏截图均成功；另以 Windows 原生平台进行隐藏初始化检查。

自动审计报告位于**源码项目**的 `artifacts/history-audit.json` 和 `artifacts/packaged-verification.json`；后者记录实际 EXE 哈希、时间、各页面退出码和随包内容核验。重建后可重新运行上述工具更新报告。预览与可读取的急报示例存档也在 `artifacts/`。

打包过程中发现系统 PATH 中其他软件的 ICU/UCRT 同名 DLL 会被错误收录；构建脚本现使用隔离的子进程 PATH，保留本项目解释器、Qt 与系统组件。最终独立程序重新验证。未改动用户全局 PATH。
