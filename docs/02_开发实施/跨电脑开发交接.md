## 新电脑恢复

安装 Git、uv 和 Codex，在克隆的项目根目录执行：

```powershell
uv sync --locked --all-groups
uv run pytest -q
uv run ruff check src tests tools
uv run dynasty
```

项目包含源码、文档、素材、历史资料、测试和验收产物。虚拟环境、解释器缓存、构建目录及 dist 成品不进 Git，需要时按 README 重建。2026-09-10 文档记录 475 项测试通过；本次 Git 初始化未重跑，不将历史结果视为本次验证。

## 需要单独迁移

- 游戏存档和自定义剧本：旧电脑 `%LOCALAPPDATA%/MingDynastySimulator/`，复制到新电脑对应位置。
- Codex 会话：不在游戏仓库中；使用客户端支持的聊天移交，或另外保留本地会话备份。本文件只提供开发上下文，不替代完整聊天记录。
- 自定义技能：按需迁移用户目录 `.codex/skills/game-design-skill/`；插件在新电脑安装并登录。
- 已打包 EXE：如果要保留原版交付，另外复制旧电脑的 dist 文件夹。

请在新电脑验证启动、测试和旧存档读取后，再清理旧电脑。
