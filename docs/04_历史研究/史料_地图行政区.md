# 地图与行政区史料：首版资料包

> 2026-09-10 分类说明｜历史研究资料：用于查证和设计参考，不表示已纳入运行模拟。 [当前实现核对](../00_项目总览/系统索引与实现状态.md) · [工作文件总入口](../README.md)

本资料包采用 **1500 年／弘治十三年作为临时开局基准**。已下载全国地理原文及一幅历史参考地图，建立可检索的行政名称目录。**当前互动地图是两京十三布政使司的治所所在城市示意，尚无经过核准的 1500 年省界多边形。**

## 来源与实际精度

### 1. 行政名称：公开原典，保留两个转录版本

下载 [《明史》卷 40](https://zh.wikisource.org/wiki/明史/卷40) 至 [卷 46](https://zh.wikisource.org/wiki/明史/卷46)，并下载 [四库全书本卷 040](https://zh.wikisource.org/wiki/明史_(四庫全書本)/卷040) 至 [卷 046](https://zh.wikisource.org/wiki/明史_(四庫全書本)/卷046)。14 份原文合计约 38.2 万字符，原始修订版本固定在来源清单中。

- 原典属于公共领域；保留维基文库转录及编辑贡献的署名与 CC BY-SA 4.0 来源信息。应用代码的许可与外部资料许可分别处理。
- 两京十三布政使司清单及治所依据地理志序、各区总叙与府志核对。
- 府州县数据使用章节标题、段首名称、`倚`、`府东／州南` 等位置标记抽取；行政隶属先按原文布局与方向标记建立索引，尚未逐项完成时点复原。
- 每条记录有 `source_ids`、`source_line`、`source_excerpt`、`verification_status`、`temporal_status`。每个县的 `second_transcription_name_match` 仅表示规范化后的名称能在同卷四库本找到，**不是“该县所有事实已核准”**，也不代表两个独立历史证据。
- 明确校正了 7 个县名显示错误：井徑→井陘、成安安→成安、徑→涇、教義→孝義、扶鳳→扶風、浙江蒲江→浦江、柷嘉→𥔲嘉。原名、校正说明和原文均保留。江西的南唐府显示名据四库本及同段上下文校正为南康府。
- 另有 37 个县名未通过第二转录的简单字符串核对，部分因四库本异体字、缺字模板或 OCR 差异，已列入复核文件。不能据此判断原县不存在。
- 常规转录卷 40 序言含与四库本明显不一致的文字（包括“天与地卑”一段），已留存两版，不把该处叙述作为游戏规则或精确史实依据。

## 1500 年开局的边界

首版仅启用 15 个大区。下级行政记录保留 `active_in_scenario: false`，表示可查阅史料、不能直接作为已核准的开局模拟值。原文明确存在开局后才改置的例子：

- 昌平在原书以“州”列出，但原文记正德元年升州，1500 年应回溯县制；其下顺义、怀柔、密云的隶属也要同步回溯。
- 江西安义县记正德十三年析置；不能放入 1500 年现行县表。
- 湖广城步县记弘治十七年改置，新田县记崇祯十二年置。
- 云南保山县记嘉靖三年改置；贵阳军民府、安顺军民府等也需按原书改制过程逐项回溯。
- 原书人口、户数同时有洪武二十六年、弘治四年、万历六年等统计。本包没有把这些数字混为 1500 年人口或国库初值。

暂留用户确认／后续研究：最终具体开局年月；全国下级行政时点复原的精度；边疆卫所和土司是否进入第一版可管理地图；精确省界所用底本和许可；转录异文与未分类的卫所／土司复合段落。当前安排不阻止行动力、朝政和过回合框架开发。

## 复现与验证

在项目目录运行：

```powershell
uv run --group research python tools/download_geography.py
uv run --group research python tools/download_geography.py --offline
```

默认重用已下载源文件；`--offline` 完全从现有快照重新生成。`--refresh` 会抓取新修订并更新哈希，结果可能随转录变化，需重新审查，不建议静默覆盖发布资料。

本次已检查：21 个来源的 SHA-256 与本地文件一致；15 个大区完整；1,827 条下级记录 ID 无重复、父 ID 存在、来源 ID 可解析；所有县及府州记录保留原文定位；GeoJSON 为 Point 与纯陆地背景。该验证证明文件和引用结构可用，不替代历史边界及 1500 年下级建制的逐项校勘。


## 固定种子抽检与追加修复

按随机种子 `1500`，每个大区抽取一条县及一条府／州，共 30 条，逐条核对名称、上级、所属大区及 `source_excerpt`。记录见 `docs/04_历史研究/地理抽检_种子1500.json`。修复后，30 条在原书跨时期参考编排中自洽；其中安义、保山、归德府等明显晚于临时开局，仍保留时点待核标志，没有将抽检通过改成“1500年有效”。

抽检发现广西凭祥州被章节布局误挂镇安府。继续检查同类正文后，共修正 10 个原文明示直隶布政司的州：广东罗定州，以及广西田州、归顺州、泗城州、向武州、都康州、龙州、江州、思陵州、凭祥州。保留 `source_layout_parent_id` 和修正说明；没有把奉议州、新化州等后续又改属府的记录一律改成直隶。

同时合并两条转录标题错误造成的空重复记录：苛岚州按正文及四库本校正为岢岚州；邓州按正文及四库本校正为邓川州。府州等记录因此从 656 条减至 654 条。现有行政索引无空证据条目；名称、类型与段首行政名检查未发现“东有某山／西有某河”等叙述被直接误作府州名称。该检查不能证明整部文献没有其他转录、历史隶属或排版错误。
