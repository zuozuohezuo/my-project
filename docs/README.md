1. **[系统索引与实现状态](00_项目总览/系统索引与实现状态.md)**：哪些能运行、哪些只是入口、哪些未实现，附代码与验证证据。

## 文件分类

| 目录 | 放什么 | 使用方式 |
| --- | --- | --- |
| `00_项目总览/` | 系统状态、待确认、整理说明 | 开始讨论和确认进展时先读 |
| `01_系统设计/` | 按系统分组的现行规则、设计依据和候选 | 看清每篇的确认范围；M03 三阶段规则虽然原名含“试玩”，主要承担现行规则职责 |
| `02_开发实施/` | 阶段实施计划 | 区分计划提出时点与当前实现，完成过的计划仍可追溯 |
| `03_试玩与验收/` | 操作说明、各版本测试和交付记录 | 按日期及版本核对；旧验收数值不覆盖新规则 |
| `04_历史研究/` | 史料说明、官制参考和地理抽检 | 支持史实依据，原始与结构化数据仍在 `data/history/` |
| `90_归档/` | 被替代的框架、旧引擎候选和 M03 方案 | 解释历史决策，不作为现行实现依据 |
| `99_模板/` | 可复用文档格式 | 按需复制；模板中的空项不是已确认需求 |
| `licenses/` | 第三方许可和元数据 | 保留原路径和文件，属于交付资料 |

## 源码、参数和成果在哪里

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 运行代码 | [src/dynasty](../src/dynasty) | `core/` 管规则，`ui/` 管界面 |
| 新局演示参数 | [data/config](../data/config) | 当前局保存自己的配置副本；修改文件不会自动重置旧存档 |
| 自动验证 | [tests](../tests) | 按系统的核心、集成和 Qt 测试 |
| 研究／截图／打包工具 | [tools](../tools) | 工具职责不等于运行中世界规则 |
| 截图、示例存档、机器验证结果 | [artifacts 成果导航](../artifacts/README.md) | 保持脚本输出路径稳定，说明类验收已迁入文档目录 |
| 可执行交付 | [dist](../dist) | 各版本完整目录保留；这里是打包快照，编辑其中副本不会改变源码 |
| 构建和环境 | `build/`、`.venv/`、`.runtime/`、缓存目录 | 生成物或依赖，不作为工作文档来源 |

使用 skill 的来源资料位于 [artifacts/skill-research](../artifacts/skill-research)，独立于游戏设计结论。开发参考链接可能指向未随 EXE 打包的源码／artifacts；请在完整项目里阅读。
