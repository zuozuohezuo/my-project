# 工作文件整理说明与迁移清单

日期：2026-09-10。返回[总入口](../README.md)。

## 整理原则

本次按文件用途分类，并沿用现有系统编号。设计与实现采用两套状态；史料、旧方案和旧验收不再与现行规则混读。没有擅自批准候选方案或新增玩法。

根目录 README、总框架和技术方案继续保留，作为启动、全局设计和工程入口；它们也被构建脚本引用。许可目录保留，截图、演示存档及构建产物保持现有路径。两份人工验收说明从 artifacts 归入试玩验收目录。

`docs/01_系统设计/` 中的专题仍保留原始正文和确认过程，只追加分类说明并修复相对引用。M05 与 M06 的共享设计放在同一目录，减少同一规则重复维护。没有为未设计系统创建空文档。

## 查阅优先级

1. 用户最新明确决定及对应现行专题决定设计意图。
2. 当前代码、配置和实际验证决定“现在做到了什么”，不能反过来替代设计确认。
3. 系统索引用于导航；发现意图与实现不同应写出差异。
4. 旧方案与验收按时间和版本阅读；模板内示例和参考技能不是正式规则。

M03 新局以三阶段规则为准。M06 新县以 09-09 职业人口规则为准；旧县存档仍按冻结 v1 运行。年龄组说明或缺粮四旬 928 人等旧验收数字保留，但不用于描述新县。
