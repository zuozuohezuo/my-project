## 当前页面

游戏左栏“06 皇帝档案”包含基础属性、技能及性格与追求三个页签，显示三类 13 项属性、六项初始技能和九组稳定性格；点击技能卡片查看说明。“手动调整…”保留作弊入口，可输入超过 100 的非负整数，全部校验通过后一次应用；取消不改值，修改不耗行动力或诏书，不影响朝政活动草稿。修改随当前局保存，旧 v1 存档缺少皇帝档案时补充默认。

演示基础属性统一为 50，技能为 0，九组性格统一居中 50。这些仅用于页面与存档联调，不是历史人物评价或已定量表；页面释义用于说明项目，具体属性权重、成长及判定仍待设计。姓名、年号与健康来自当前游戏，体质不改写健康。

## 已确认：健康栏与修正栏

基础属性页内增加健康栏，包含整体健康度与压力，两者范围均为 0–100。身体部位仅在存在异常时显示疾病、残疾等具体状态；全部健康时不显示部位明细。健康不并入原有 13 项基础属性，体质仍是独立的基础属性。

修正栏记录当前人物的长期或短期修正。修正可以改变基础属性，也可以提升某项技能的效果。基础属性底值与修正分别记录，技能效果变化与已学会的熟练度分别显示。

### 当前实现约定

以下叠加、时长及手动编辑规则用于本次页面实现，尚非用户确定的最终平衡公式：

- 整体健康继续使用当前局唯一的健康数值；压力默认 0。异常部位以部位、类型（疾病／残疾／伤势）、状态名称记录。不从疾病名称自动推导健康变化或修正，后续疾病效果另行设计。
- 属性修正使用有符号整数点数，同一属性相加；当前值为底值加修正，最低为 0，不以 100 封顶。页面列出当前值、底值和修正合计。
- 技能效果修正使用百分比点，同一技能相加；总效果从 100% 起算，最低为 0%，无固定上限。技能熟练度保持不变，例如书法效果 +20% 对应当前效果 120%。具体技能事件和政务结果尚未结算。
- 每条修正记录名称、来源、目标、数值、期限；多项效果可以分行记录。长期持续至移除；短期暂按剩余旬数记录，每成功完成一旬扣 1，到 0 移除。暂停、失败、刷新与读档均不扣时长。
- 健康栏“调整…”与修正栏“管理…”提供手动编辑，全部字段校验后一次应用；取消不改变状态。健康改变 AP 时，如本旬已进入执行、存在未完成三旬计划或已有安排超出新 AP，则拒绝冲突的修改；朝政草稿不会被静默删除。
- 新状态和修正随游戏保存，旧 v1 存档补充压力 0、空异常列表和空修正列表。普通属性编辑保留这些状态。自动疾病、压力变化、恢复、学习成长和事件概率仍未启用。

## 已确认：能力分为基础属性与技能

### 基础属性

| 类别 | 属性 |
| --- | --- |
| 智力类 | 逻辑、情商、记忆力、洞察力、创造力 |
| 身体类 | 力量、体质、敏捷、感知、颜值 |
| 意志类 | 自律能力、情绪抗性、胆量 |

共 13 项。基础属性变化相对缓慢和固定；尚未规定完全不变、具体成长途径或年龄变化曲线。

### 技能

用户列出的技能示例：政务处理、军事策略、识人能力、话术、书法、学识。此清单允许继续扩充。

- 技能可通过学习增长。
- 技能增长速度与基础属性和性格挂钩。
- 政务处理、军事策略、识人能力等应归入技能，不沿用上一轮将综合能力作为基础属性的建议。
- 基础属性不限制技能成长上限。低基础属性人物可以通过足够学习达到同等技能水平。
- 用户明确提出“不限制技能上限，留下玩家作弊的窗口”。保留玩家修改与超出常规数值的空间，不以基础属性或常规等级标签强行封顶技能。
- 学习增长的具体公式、属性权重、技能等级、正式量表、遗忘与实践成长规则尚未确定。当前页面暂用非负整数，并已提供手动调整入口。

## 已确认：学习、常规表现与事件判定

| 场景 | 已确认规则 |
| --- | --- |
| 学习成长 | 技能通过学习增长，增长速度与基础属性和性格挂钩。 |
| 常规表现 | 技能相同，正常表现相同；不因基础属性更高而额外提高该技能的常规表现。 |
| 事件判定 | 相关基础属性与技能共同参与判定。在技能与其他判定条件相同时，相关基础属性更高，成功可能性更高。 |

用户以“识人能力同为熟练、洞察力不同”的人物说明这一区分。两者的正常识人表现相同；遇到需要洞察力参与的识人事件判定时，洞察力较高者的成功可能性更高。不能把基础属性解释成持续提高所有日常技能表现的通用加成。

判定关联哪些属性与技能、事件难度、成功概率公式和结果类型尚未确定。性格影响学习速度已确认，是否也参与事件判定则仍待讨论。基础属性不限制技能成长上限；因此学习速度差异不应被转换为低属性人物无法突破的技能门槛。

建议由事件明确声明何时需要判定、使用哪些属性与技能；常规技能使用依照对应技能规则处理。不能为了套用基础属性加成而默认将全部日常行为转为事件判定。此触发方式为设计建议，尚未确认。

## 建议：明确容易重叠的属性边界

以下定义用于下一轮讨论，尚未获得用户确认。

| 属性 | 建议边界 |
| --- | --- |
| 情商 | 理解他人情绪与社交处境的基础能力；学习到的表达和应对技巧由话术等技能表达。 |
| 情绪抗性 | 承受自身情绪冲击的基础能力；当前压力已在健康栏独立记录，二者联系待定。心理影响已确定归压力、身体或修正，不另设心理状态栏。 |
| 感知 | 发现声音、表情、动作等外界细节的基础能力。 |
| 洞察力 | 解释已经接触的线索、发现关联与推断意图的基础能力；识人则是长期学习形成的人物判断方法与经验。 |
| 自律能力 | 执行既定计划、克制即时诱惑的基础能力。 |
| 性格 | 人物的兴趣、偏好与行为倾向，可按技能和学习情境影响增长速度；性格与自律不能机械重复表达同一项加成。 |
| 体质与健康 | 体质属于基础属性；健康继续表示当前身体状态，并沿用健康影响每旬行动力的已确认规则。二者具体联系待定。 |

## 建议：技能与基础属性的关联示例

下表只讨论学习适性，不直接决定事件使用哪些属性，也不建立属性对技能的上限限制。基础属性参与事件判定、同技能常规表现相同的规则见上节。列出的关联属性不表示同等权重。

| 技能 | 候选关联属性 | 学习内容示例 |
| --- | --- | --- |
| 政务处理 | 逻辑、记忆力、洞察力 | 熟悉行政流程，理解财政资料，学习分析奏章与执行条件。 |
| 军事策略 | 逻辑、洞察力、创造力 | 研习兵书、分析战例、推演补给与战略方案。 |
| 识人能力 | 洞察力、情商、记忆力 | 学习人物判断方法，对照人物言行与长期表现。 |
| 话术 | 情商、逻辑、创造力 | 学习表达、说服、谈判和应对技巧。 |
| 书法 | 敏捷、感知、记忆力 | 临帖、运笔与结构练习。 |
| 学识 | 记忆力、逻辑 | 学习并理解知识；是否进一步划分经学、史学等领域待定。 |

建议每项技能先关联少量确有作用的属性。自律能力、情绪抗性、胆量以及具体性格，可依据学习安排与情境参与成长，不默认对所有技能等比例加成。性格影响学习速度的原则已确认，但具体方向与幅度未确认。

## 待讨论

1. 常规表现与事件判定的边界、触发方式、关联属性与技能，以及事件成功率规则。基础属性参与事件判定、同技能常规表现相同、基础属性不限制技能上限均已确认，无需再次确认。
2. 基础属性的量表、初值来源与缓慢变化方式；技能的量表、等级与初值。
3. 技能除了专门学习，是否也能通过实际使用、教师指导或事件获得成长？
4. 九组性格已经选定；每项性格怎样影响不同技能的学习速度、欲望产生和行动反馈仍待设计。
5. 学识等宽泛技能是否细分，基础属性与技能清单如何继续扩展。
6. 作弊入口已支持基础属性、技能、健康、压力、身体异常与修正；后续可讨论其他项目。常规等级和显示刻度应保留超出常规数值的空间，不将人物基础属性作为技能修改或成长的上限门槛。
7. 压力与健康的自然变化、疾病和残疾的发生及恢复、异常状态与修正的关联，以及修正叠加和持续时间的正式规则。

用户已选定九组稳定性格，保留近期欲望和长期野心，由玩家完成以满足皇帝需求并提供游戏方向。心理状态不单列，直接影响已有压力、身体或作为修正。第三页签采用“性格与追求”，当前原型支持性格调整、活动型目标设立、进度和完成记录；具体奖励未定。确认范围与后续候选机制见[人物性格与追求](../M02_性格与个人追求/人物性格状态与动机_建议.md)。
