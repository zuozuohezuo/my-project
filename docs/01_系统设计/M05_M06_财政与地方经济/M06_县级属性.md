## 1. 行政与经济层级

暂按 **基层州县 → 府州级 → 更大区域级** 表达三级经济结构。“州”在具体剧本中属于哪一级、直隶地区如何对应、最高一级采用什么正式名称，后续结合已核历史关系确定；不把所有历史地区强行套成完全一样的隶属链。

本轮已用县级基础单位的方向取代先前“省／州为最小单位”的方案。建议县负责基础生产、居民消费和当地存量；上级汇总辖区情况，处理跨县、跨府调拨和自身事务。府、省汇总后的总人口和总土地不能再参加一次基础生产，形成重复产出。

上级机构可有自己的公库和公共支出。辖区汇总钱粮与上级自身库存分别表示，不因汇总就转移所有权。府城等人口若已计入某基层单位，也不能再作为额外一份人口累计。

## 2. 已采用的四个基础栏目

| 属性组 | 建议细化内容 | 边界 |
| --- | --- | --- |
| 人口 | 总人口、户数、年龄结构、可用劳力、迁入迁出或流民状态 | 总人口为唯一总量；年龄、职业、贫富和流民身份属于不同维度或子集，不能全部相加 |
| 土地 | 总面积、耕地、其他用途面积、可开垦潜力、地形、地力与水源条件 | 土地用途按互斥面积统计；地力、灌溉等是特征，可开垦潜力通常是现有地类的子集 |
| 当地特产 | 优势产品／资源的种类、品质、开发状况及相关产业 | 天然资源、农业产品和加工制品分别表达；现有产量从对应生产过程计算 |
| 当地修正 | 来源、影响项目、强度、持续期或失效条件、适用范围 | 长期与短期分开；同一效果不同时在基础属性和修正中重复生效 |

人口结构、户数、劳力、流民等已作为首版内容方向保留；年龄段界线、是否需要逐户记录、土地分类及具体计算口径继续细化。可用劳力可由人口结构与状态推算；同一批劳力在种田、服役与工程之间的分配必须协调。

特产建议理解为当地的优势生产内容，例如茶叶、丝织品、矿产或某类工艺品；有这种优势不自动意味着每旬获得固定钱财，也不先限制其他县绝对无法生产。若产业规模由生产经营记录保存，特产栏引用它，不另存一份互相独立的规模。

当地修正可包括灾害余波、战乱损伤、临时税收减免等候选。水源、土壤等长期条件如何作为基础字段或长期修正表达，须选择一致方式。例如地力已经进入产量计算时，同一“土壤肥沃”标签不再额外重复加成。减免若由财政政策产生，县修正栏可以展示该政策的影响，不再独立扣减第二次税额。

## 3. 已采用的四个经济运行栏目

| 属性组 | 建议内容 | 为什么需要 |
| --- | --- | --- |
| 钱粮与物资 | 民间钱财、存粮、种粮及物资；当地公库的关联展示 | 决定能否维持生活、缴税、采购和救急 |
| 基础设施 | 水利、道路、仓储、集市等的规模与维护状况；文教和医疗条件可后续扩展 | 决定资源能否被有效生产、保存和运送 |
| 生产经营 | 种植安排、主要行业、作坊或采掘规模、从业劳力、生产技术与投入需求 | 将土地、人口和特产连接成实际生产过程 |
| 民情与秩序 | 民心、治安等状态；生活保障和灾情汇总 | 让经济变化影响地方社会，并能反馈到生产与治理 |

用户已同意将这四组一并纳入暂行框架；具体量表与公式继续设计，不立即采用统一的 0–100。县级“富裕”“饥荒”等展示状态可由库存、分配、粮价及消费缺口推导，不一定新增一个自由变化的基础数值。

民间库存与公有库存保持归属区别；当地公库引用 M05 的财政账目，不在县模型内复制余额。在途货物由运输记录持有，到达后才计入接收方库存。用户已要求简化：建筑和田地产出按归属入池，消费与生产投入直接扣对应池，不设用途预留和占用余额；播种需要的种粮在实际投入时扣除。

水利等设施的实际规模与维护状况可以影响有效灌溉，避免“水利等级”“灌溉面积”“灌溉修正”对同一设施重复计算收益。建设中的工程引用持续任务记录，完成后才按规则更新设施。

民心、治安、生活保障与官员操守分别表达；不因某个官员清廉，就直接把全县所有状态设为良好。人口增长、生产变化、商业流通和社会状态之间的具体关系后续讨论。

## 4. 计算结果与关联信息

建议将预计／实际产粮、本旬消费、人口增减、应征／实征、粮价、收支趋势和粮食可支撑时间放在结果栏。它们来自基础数据及当期过程，已经实际产生的结果可以保存为历史记录，但不能作为另一套无关联的基础值独立增长。

县名、稳定 ID、治所位置、所属上级属于基础身份；县官及有效职权关联 M04，税制与公共账目关联 M04／M05，工程、灾害和待办关联持续任务，邻接地区、路线与在途货物关联运输体系。关联展示不代表把所有数据所有权都放进一个县对象。

玩家可见县档案继续遵循 M07：真实人口、粮食与产业情况，和皇帝收到的户籍、钱粮及灾情报告分别保存。县级细化不自动给予玩家精确全知信息，报告来源与时点的呈现以后设计。

## 5. 人口的首版细化方向

2026-09-09 人口规则已更新：保留实际人口、户数、流民与暂居身份；取消年龄组，按职业阶层和收入财富分别统计。默认劳动力比例 50%，年出生率 3%、年自然死亡率 2%，按一年 36 旬折算并保留小数余量。职业、财富与自然增减的当前规则见[人口职业与收入](M06_人口职业与收入.md)。征兵、工程及迁移对劳力的占用后续接入。

| 内容 | 建议口径 | 主要影响 |
| --- | --- | --- |
| 实际人口 | 当前实际居住于县内的人数；流民进入后也纳入一次 | 日常消费、生产与地方生活压力 |
| 人口结构 | 农民、劳工、手工业者、商人、地主、贵族、官员；按各群体收入另分贫困、普通、富裕 | 职业结构、生活需求及财富差异 |
| 户数 | 单独保存家庭组织数量，是否逐户建档另定 | 户籍、家庭生计及未来按户办理的事务 |
| 流动身份 | 本地居民、暂居或待安置流民等分类，与职业、财富交叉 | 安置、迁移及土地劳力分配 |
| 可用劳力 | 人口乘劳动力比例（默认 50%），再计入健康和劳动状态 | 农业、作坊、运输、服役、工程的共同投入来源 |
| 本旬人口变化 | 出生、死亡、迁入、迁出分别记录 | 解释总人口为何变化，年度统计由记录汇总 |

居住身份、职业与财富采用不同分类维度，不能将全部分类人数加在一起。户籍人口作为行政记录或报告，与实际居住人口分别解释；失真或过时的户籍数字不改变真实人口。

建议人口变化遵守：**期末实际人口＝期初实际人口＋出生－死亡＋迁入－迁出**。公式只是人数记账关系，不预先规定出生、死亡和迁移怎样生成。跨县迁移只在相应离开／进入时记账，旅途中的群体单独记录，不能同时成为两县的实住人口，也不能无故消失。

劳力先折算为可投入的劳动量，再按本旬或相应生产阶段分配；正在服役、修河的劳动投入，会影响能分给其他工作的数量。是否允许兼业、季节切换及不同劳动类型的效率，另行设计，不把一次登记职业当作永不可改变的身份。

## 6. 土地的首版细化方向

| 内容 | 建议口径 | 主要影响 |
| --- | --- | --- |
| 县域面积 | 一份地理总量，统一计量口径 | 限定用地总量；行政边界变化时才按规则调整 |
| 用地结构 | 耕地、林地、草地、水域、聚落及其他用地等互斥分类，类别可继续调整 | 农业、采集、建设及后续产业空间 |
| 可开垦潜力 | 现有地类中适合转为耕地的部分 | 开垦的规模、成本与前置条件 |
| 耕地质量 | 地力、地形和水源等条件，先按相近条件的土地群汇总 | 不同作物的适宜性、生产能力与灾害影响 |
| 灌溉覆盖 | 由土地位置、水源及实际水利设施共同支持的有效覆盖 | 与基础设施栏衔接，同一水利收益只计算一次 |
| 土地权属 | 保留民间、官府、皇家等归属方向；具体历史分类另核 | 确定田地产出进入哪个资源池；税收等后续设计 |

用地分类、地形、地力和权属是不同维度。例如一片土地可以同时是耕地、山坡地、民间所有，面积仍只记一次。用户已同意土地权属纳入土地栏；它不另构成第九栏。县域总面积、用地结构、可开垦潜力与土地质量的首版方向一并采用，具体分类和单位仍待细化。

开垦建议记为原地类减少、耕地增加；可垦潜力是现有土地的一部分，不能再加到县域总面积上。土地面积的计量单位与历史田亩资料的换算以后核定，不在本轮填入县级真实初值。

耕地表示可安排种植的土地条件，实际种植安排由生产经营栏负责；播种还需劳力、种粮及其他投入，收获随生产阶段发生。农业产量从实际种植及其条件计算，开垦完成或耕地面积增加本身不立即生成粮食。

## 7. 接下来的设计顺序

人口与土地的首版方向、[生产经营架构](M06_生产经营.md)已采用，钱粮已采用按建筑田地归属入池、消费直接扣池的简化方向，消费已确认共用民间池，短缺时财富越低惩罚与死亡率越高、上层向下层转化，接下来细化[群体需求与后果](M06_钱粮物资与消费.md)；随后细化设施、特产与当地修正的作用，以及民情反馈。八个栏目和已确认的细化方向不再重复询问是否采用。三级汇总与跨县运输接口同步明确，税收公式和官职作用留待其后的联合设计。

当前只是县级属性框架；没有填入县人口、耕地或资源初值，没有改变旧的省州展示与存档，也未决定所有历史县都已经能够独立运行。
