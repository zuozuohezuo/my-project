## 1. 模拟单位与自主经营

建议一个县按产品、经营主体和相近生产条件汇总产业条目，例如民间粮食种植、民间织造、官营矿场、皇家庄田。这些只是游戏中的示意分组，不代表已确定的历史产业清单或经营制度。各县可以拥有不同条目，后续再决定是否需要细分到单个大型矿场或庄园。

日常经营建议由相应农户或经营者依据自身资源、所知行情、预期收成、风险和有效政策持续安排。地方官办理授权范围内的公共事务；皇帝通过政策、工程、救济、征发或特定指派影响条件。既有生产无需皇帝逐县下令开始，也不逐项占用皇帝的个人行动点。

## 2. 每项产业保留什么

| 内容 | 建议记录 | 作用 |
| --- | --- | --- |
| 产品与经营主体 | 生产什么、由谁经营；另关联土地或设施所有者 | 确定经营安排与资源池归属，产出按建筑和田地所有权入池 |
| 经营规模与生产条件 | 实际种植面积、作坊能力、矿场能力等；引用土地、设施和资源条件 | 表达现有生产能力，扩张需要时间与投入 |
| 劳力安排 | 各生产阶段所需劳动量、本旬实际分配量 | 与农业、运输、服役和工程共享当地劳力 |
| 物资投入 | 种粮、原料、燃料、饲料、工具维护等按产业需要列出 | 实际投入时校验对应池并直接扣除，不设预留分类 |
| 技术与熟练程度 | 相应行业的生产技术和劳动熟练程度 | 影响转换效率、质量或损耗，具体效果后续确定 |
| 生产周期与状态 | 播种、生长、收获，或加工批次、采掘进度；缺工、缺料等原因 | 决定何时投入、何时形成产品，以及中断后果 |
| 产出与经营结果 | 预计产量、实际入库、库存变化、销售与成本记录的关联展示 | 帮助判断经营情况；预测和产值不作为库存或现金 |

经营规模采用适合该产业的实际量或明确抽象单位，暂不统一改成 0–100 的“产业等级”。技术、熟练程度和地区优势分别说明作用，同一条件不重复叠加。

经营安排可以由对应经营者执行，但首版产出直接按建筑和田地归属计入民间、官府或皇家资源池，不另细分经营者与产权人的入库分成。职业仍不作为不可改变的固定身份。

## 3. 已采用的生产类型框架

| 类型 | 示例 | 周期差异 |
| --- | --- | --- |
| 农业种植 | 粮食、棉麻、茶等 | 随作物与地区条件推进种植阶段，在相应收获节点入库 |
| 畜牧、渔业与林业 | 牲畜、鱼、木材等 | 各自处理生长、繁殖、捕获或采伐及资源恢复，不能套同一个固定旬产量 |
| 手工业加工 | 纺织、制陶、冶炼等 | 消耗对应原料和燃料，推进加工批次后形成产品 |
| 资源采掘 | 矿石等 | 依赖当地资源、开采条件、劳力和设备；资源消耗与停工规则待定 |

这是结构上的预留，不要求首个原型同时实现全部产业。建议先用一种粮食验证完整生产周期，再用一条简单加工关系验证原料转换；最终首批作物、商品和单位仍待讨论。商业与运输属于商品流通，随后展开；销售本身不再生成一份被售商品。

## 4. 一旬怎样推进生产

建议每旬依据当前季节、既有生产阶段和已生效安排更新劳力与投入需求，协调资源后推进生产，并记录实际消耗、完成进度和入库结果。旬是观察和结算节奏，不要求各产业都在每旬收获，也不改变 M03 的整旬活动规划。

- 农业允许在未收获的旬持续需要劳动和物资。各阶段对劳力的要求不同，缺工可以影响面积、预期收成或收获损失；不将不同阶段一律折成相同的减产率。
- 作坊和采掘按相应周期完成产出；缺料时不能只扣钱就生成产品。暂停、积压及恢复的规则按产业性质细化，不一概作废全部既有进度。
- 同一群人可以按季节或投入时间分配不同工作，但当期劳动量只能分配一次；经营者之间怎样协调雇工与家庭劳动留待经济主体设计。
- 种粮、原料和设备维护在实际投入时直接从对应资源池扣除，不设置预留或占用分类；余额不足时按生产规则减少或暂停投入。同一份资源不能实际扣用两次。
- 地力、水利、特产优势、技术与灾害分别通过对应生产环节起作用。例如灾害减少田间预期收成，不再同时从既有粮仓扣除同一份粮食。

## 5. 产出怎样成为收益

生产完成时，钱粮或物资按建筑与田地归属进入对应资源池，数量只入账一次。生活消费、生产投入、交易和税收发生时直接改变相应池；首版不额外设置种粮保留余额，也不在入库前通过租佃合同拆分产出。后续是否展开租税或报酬规则另定。

建议区分：实物产量、商品产值、销售回款、经营成本和经营收益。只有真实交易或其他已定义的货币来源才改变货币余额；生产一批布不会同时自动增加一笔等额银钱。商品卖给其他地区时，对方支付且货物发生转移，县与上级汇总也不能重复获得收益。

土地所有者、经营者、雇工和官府不能同时各得到一份完整产出。官营或皇家经营的投入与收入也应关联其对应账目；皇家产业利润汇入内帑的具体规则在 M05 细化，不将民间或公共产出自动汇入内帑。

## 6. 能带来哪些决策

例如，农忙期间征发一批民夫修河，会减少同期留给农业的劳力，可能影响收成；水利工程达到生效条件后，再改善后续生产条件。皇帝可在工期、征发规模、雇工或地方救济等方向作选择，具体可用操作由政策、权限与资源共同确定。

再如，扩大织造既需要原料，也需要劳力和生产能力；布产出增加后还取决于销路，才能形成经营者的货款。县内产业选择因此会与粮食保障、贸易、资源禀赋和政策发生联系。

生产经营的基本关系已采用，具体数值强度、事件概率和操作目录尚未确定。下一步细化[资源池直接扣除与群体消费](M06_钱粮物资与消费.md)，再衔接市场流通、税收和机构分工。
