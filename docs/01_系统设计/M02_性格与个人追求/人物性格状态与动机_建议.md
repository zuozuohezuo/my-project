2026-09-07。用户已选定九组稳定性格，保留近期欲望和长期野心；心理影响归入已有压力、身体及修正体系，不单列心理状态栏。下文区分这些确认与尚待设计的机制。现有 13 项属性、六项技能、健康／压力、身体异常和长短期修正继续保留。

## 页面组织

皇帝档案第三个独立页签采用“性格与追求”，内部包含稳定性格、近期欲望、长期野心三块。心理状态不放在本页，不新增独立心理数值或状态列表。心理影响直接体现到健康页已有的压力、身体情况，也可以作为现有修正记录。

页面应回答：这个皇帝重视什么、眼前想做什么、长期想达成什么，以及玩家如何去完成。欲望与野心需要玩家主动达成，用于满足皇帝需求和提供游戏方向。

## 一、稳定性格

性格侧重价值取向与偏好，变化慢。基础属性描述人物的能力，两者分别记录。已确定保留原五组并添加四组，共九个倾向；“淡泊—好名”不纳入。具体数值和效果仍为实现约定或待讨论项。

| 已选倾向 | 候选影响（具体规则待定） |
| --- | --- |
| 仁厚—严酷 | 对惩罚、宽恕和他人苦难的感受，处理冲突时偏好的手段 |
| 宽信—多疑 | 对不确定信息与委派的态度，安全感和查证需求；不直接提高识人准确度 |
| 守成—求变 | 对祖制、改革和新事物的接受意愿；不等同于创造力 |
| 质朴—奢华 | 对生活规格、消费和享乐的偏好；不等同于自律能力 |
| 放权—掌控 | 对委派、自主决策与亲自过问的偏好；不代表实际政治权限 |
| 谦逊—自负 | 对自身判断、认错和不同意见的态度 |
| 重情—秉公 | 人情与原则冲突时的处置偏好 |
| 守信—权宜 | 承诺和局势变化之间的取舍 |
| 合群—独处 | 偏好的相处及活动方式 |

可另用少量兴趣标签描述兵学、书法、经史、骑射等兴趣，参与学习速度与活动偏好。兴趣不能直接增加已学技能水平，也不构成技能上限。

不再把勇敢、自律、聪明等作为另一组性格数值。高情商不等于仁慈，多疑不等于洞察力高，好享受不等于自律低。

## 二、心理影响的归属

用户明确要求不在新栏展示心理状态。愤怒、忧虑或振奋等事件造成的心理影响，直接通过已有压力、身体情况或修正表达。具体产生条件、强度和消解方式仍待确定。

压力继续使用现有 0–100 状态；疲劳、疾病和残疾继续归健康体系，不再为同一心理冲击建立另一套并行记录。具体修正通过原修正栏查看来源、作用与期限。

心理因素如何改变压力、身体或修正的数值尚未启用，不默认从性格标签直接推导某项疾病。

## 三、近期欲望

欲望是具体的眼前诉求，来自性格、当前状态和经历；不等同于一组需要每旬全部补满的资源条。后台可以有连续强度，页面先用“萌生／强烈／迫切”等程度描述，同时显示原因。

例如想出猎、想有人陪伴、想惩罚冒犯者、想得到赞誉、想修建华丽宫殿。每项记录想要什么、为何产生、紧迫程度、满足或压抑的影响。

尽量允许直接满足、替代满足、延后或克制。不同欲望可以同时存在，彼此冲突；不能全部折算为一条满意度。完成欲望也应考虑后续代价，避免所有顺性操作都自动提供无风险收益。

## 四、长期野心

野心是人物持续认同的目标，可有投入强度、具体达成条件、进展与挫败反馈。此前“一个主要目标和少数次要目标”为建议，本次不将其设为固定数量限制。

候选目标包括平定边患、恢复国力、强化皇权、平稳传位、留下文化功业等。野心的规模和执行能力分别记录，允许能力不足而目标宏大的人物。安稳守成也可以是强烈的长期目标。

性格与经历影响人物容易认同什么目标，玩家可以选择承诺、调整或放弃。变更长期目标不应成为每旬免费刷取心理收益的手段；具体变更代价后续设计。

## 五、与能力、技能及操作的结合

| 已有内容 | 建议作用 |
| --- | --- |
| 自律能力 | 决定克制即时欲望、坚持既定计划的能力；不消除欲望本身 |
| 情绪抗性 | 影响冲击引发情绪状态的强度与持续；不决定人物重视什么 |
| 胆量 | 面对危险、威胁时维持行动的能力；不等同于好战或喜爱冒险 |
| 逻辑、洞察力等 | 在适用事件中参与方案与信息判断；高能力不能让人物无条件知道真相 |
| 技能 | 处理对应事项的已学能力；同技能、相同修正下的常规表现相同 |
| 性格与兴趣 | 影响学习速度、活动偏好和行动后的心理反馈，不隐藏地改写日常技能表现 |

建议将行动限制分层：

1. **普通偏好冲突**：操作仍可执行，展示可预见的压力或欲望变化。例如奢华人物选择削减宫廷开支。
2. **强烈欲望或情绪冲突**：少数关键决定可出现明确的克制选项，使用相关意志属性；提前说明可能失败与其他处理办法。普通操作不反复弹窗，也不因刷新按钮重新抽取结果。
3. **明确的失能或剧情限制**：仅在确实无法行动的状态下禁用适用操作，写明原因与解除条件。性格本身不随意封死基本政务。

事件触发和判定方式仍待确认。克制决定是否能照计划采取行动，技能及相关基础属性决定具体事件怎样处理；不把同一事件机械拆成连续多次判定、重复处罚。

资源、职责及朝堂权限始终独立校验。人物动机不能绕过现有行动力、诏书或财政主官阻止规则。

## 六、完整情境示例

一位奢华、重情而自律较高的皇帝，近期想修建宫殿，长期又希望恢复国力。玩家决定暂缓修建时，享乐欲望仍存在；自律使其更容易坚持承诺，但不把人物直接变成节俭性格。国力改善可以推进长期目标，内心的满足与眼前欲望形成冲突。

若玩家仍要动用国库，则须提出划拨方案；财政恶劣、清廉且坚持道德原则的财政主官可以按已确认规则阻止。皇帝的欲望、野心或克制成功都不能越过此阻止。罢免后，仍由新任财政主官重新处理原方案。

## 当前页面原型的实现约定

- 九组性格暂用 0–100 位置值表示，0 偏左、100 偏右、50 居中；新局统一居中是演示初值，不是历史人物评价。支持手动调整并保存，不限制原有技能的自由修改空间。
- 近期欲望与长期野心支持玩家自设标题、说明、对应活动及目标次数。现阶段使用已开放活动的完成计数检验条件；不同 kind 分开呈现，无固定目标数量上限。
- 设立目标后，需要实际完成对应活动才获得进展。仅成功旬结算中的已完成活动计数，被替代活动不计；暂停、失败、刷新和读档不增加进度，也不追溯设立前的历史活动。
- 达标后自动记录“已满足／已达成”及完成旬，保留记录；没有一键完成或领取按钮。未完成目标可撤下，相同的进行中目标不可重复设立。
- 当前完成只确认对应需求已满足，不默认奖励压力恢复、属性、技能经验或金钱。正式满足奖励、需求的再产生、期限、放弃后果及目标之间的关系继续设计。
- 性格与目标数据随存档保存，旧 v1 存档回填居中性格和空目标。心理状态不新增字段；现有健康、压力、修正及活动草稿保持独立。

这些是使用现有活动流程实现可操作目标的第一步。长期国家目标、性格自动生成欲望、学习速度与克制公式仍待后续机制接入。

## 优先讨论的边界

九组性格维度及心理影响归属已确认，不再重复确认。后续讨论反性格操作的代价程度、欲望和野心的产生方式、具体达成条件与满足反馈。暂不固定具体权重、压力变化值、克制概率、人格变化速度和目标奖励。
